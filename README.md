# Molecular-dynamics-and-Python
Я написал небольшую программу для построения гидрофобного профиля белков на Python, использующую шкалу гидрофобности Кайта-Дулиттла. 
Она позволяет анализировать распределение гидрофобных участков вдоль последовательности, что может быть полезно для предсказания свойств белков и 
дизайна лигандов.
